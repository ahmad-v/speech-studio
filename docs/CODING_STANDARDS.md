# Coding standards

Rust first; separate GUI and algorithms. Avoid unsafe Rust in original code. Use typed errors, structured request parameters, explicit file limits and no-clobber output. Do not call shell commands from runtime. Do not add network access or use ambient private-engine paths. Use rustfmt and Clippy after toolchain resolution. Test error paths, Unicode and cancellation. Public documentation uses plain human prose, without em dashes. Record contract and dependency changes in the changelog.

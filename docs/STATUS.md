## Known gaps

The standard edition omits optional private ASR packs. A pinned local model pack or explicit local model path with expected SHA-256 is required; a user hash is integrity, not authenticity. Multilingual language auto-detection is implemented, but language-level accuracy, WER/CER, runtime RAM use and performance are not measured. Cancellation cannot interrupt inference itself. An initial English-to-French text-translation route is implemented but remains unverified with its full model pack; broader text translation and diarization remain open. The Kitten Nano/CMUdict TTS pack is pinned and hash-verified; its model repository revision explicitly marks the model package Apache-2.0, the engine pack retains Apache notices, and CMUdict carries its own BSD-style notice. Integration run 46177120953 passed offline synthesis and WAV checks with no IP network access. Native run 46177120949 passed all five targets, including the Windows static CRT configuration check. TTS remains experimental: voice quality, pronunciation, multilingual support, performance, memory, physical devices, and extracted-bundle lifecycle remain unverified. Whisper speech-to-English remains separate from general text translation; no translation corpus or language-quality validation has been run. Audio-device enumeration and playback/recording are not verified on physical hardware; recording buffers, finalization and no-overwrite behavior have hardware-independent tests. The VAD is an adaptive RMS energy heuristic, not a neural model, and has not been checked against labeled speech/noise recordings. Transcript language and rate values are estimates. SRT supports strict basic timecodes and sequential indices; overlapping segments are allowed. Version 3 audio-workspace JSON projects preserve transcript cues, an optional relative linked-audio path and the signed synchronization offset; version 1/2 projects remain readable with a zero offset, and loading linked audio is an explicit user action. Speaker labels are not stored. Cue text find/replace is case-sensitive and literal. LRC import infers cue ends from the next timestamp and assigns three seconds to the final cue; export drops cue-end precision and flattens multiline text.

The Windows ASR metadata correction is merged and targeted distribution builds passed; clean-host installed runtime inference and full package lifecycle checks remain open. Physical device tests and remaining package formats remain open. See [verification evidence](VERIFICATION.md) and [dependency review](DEPENDENCIES.md).

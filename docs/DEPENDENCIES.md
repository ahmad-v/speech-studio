# Dependencies

Cargo manifests list the exact direct requirements. The committed lockfile records the resolved versions and registry checksums. Builds use Rust 1.88.0 from `rust-toolchain.toml`. The CI checkout action is pinned to its upstream v4.2.2 commit.

A preliminary RustSec review used advisory database revision `c9f6c91a44db9d71742329e9df061279f9c4be`. The pinned Localwright revision uses Iced’s Tiny Skia software renderer and removes the affected `lru 0.12.5` dependency path (RUSTSEC-2026-0002 and RUSTSEC-2026-0253). A weekly workflow audits the current lockfile; dependency-file changes also trigger audit and license metadata inventory. Manual dispatch prepares an all-features/all-targets CycloneDX SBOM. A complete human license compatibility review and native dependency review remain open; declared Cargo metadata is not license approval.

The optional ASR feature pins Whisper 0.14.4 because 0.14.0 was yanked. The repository ships without a model or model binary.

The default audio playback feature pins Rodio 0.20.1 and uses CPAL for the native output device. Rodio's bundled Symphonia decoders handle WAV, FLAC, MP3, Vorbis and AIFF; a direct optional Symphonia feature enables the Ogg container parser because Rodio 0.20.1’s `symphonia-all` feature enables the Vorbis codec but omits the Ogg demuxer. Rodio's 0.20.1 MP4 adapter wraps seekable input without reporting its byte length, which makes Symphonia's MP4 demuxer return a seek error that Rodio treats as unreachable. Speech Studio therefore decodes MP4 audio directly with Symphonia into a seekable Rodio sample buffer, capped at 256 MiB and ten minutes. Rodio is MIT OR Apache-2.0; Symphonia is MPL-2.0 and its codec crates retain their individual license notices. Linux builds require ALSA development headers; runtime playback depends on a working host audio device. Decoder fixture tests do not verify physical playback, latency, device selection, or every codec/architecture combination. Native library license and platform behavior review remain part of the release review.

Transcript analysis adds direct, exact pins to `whatlang 0.18.0` (MIT) for offline language estimates and `unicode-segmentation 1.13.3` (MIT OR Apache-2.0) for Unicode-aware text counts. The Cargo lockfile captures the language detector's transitive dependencies. Generated portable notices must be rebuilt and reviewed for each package configuration; this records declared crate licenses, not a full native-linkage or asset review.

`cargo audit` and the SBOM task run only on the security schedule or manual dispatch, rather than every pull request. The SBOM includes all Cargo features and target-specific dependencies; it does not contain separate Whisper model assets because they are not committed or included in the baseline workflow. The private English and multilingual Tiny expansion packs have their own pinned model/license manifests and checksums; the model weights are a separate MIT-licensed asset, not a Cargo dependency.

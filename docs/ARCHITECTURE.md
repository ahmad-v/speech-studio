# Architecture

Speech Studio: Local speech and transcript workbench.

Localwright core contains serde-based domain contracts, request/response, capability and engine descriptors, job cancellation, bounded reads, no-clobber output and settings. It has no Iced dependency. Localwright UI is an optional dependency of the studios and provides a generic native operation workbench. It dispatches a single job to a background thread and receives the structured outcome through a channel. The same handler runs through the CLI. Studio processing lives in its own crate. No local server, system engine lookup or runtime network client is intentionally implemented.

Source contracts version 0.1.0-alpha.1; pre-1.0 API is unstable. Use exact shared revision after import. New breaking changes require migration notes and all four consumer checks. Candidate Rust minimum 1.85 (untested), toolchain 1.88.0 (untested). No promise of ABI stability. Current settings schema 1. Request and outcome are internal alpha interchange, not stable project file formats.

The default GUI includes a bounded local audio playback operation backed by Rodio/CPAL. A separate Iced audio workspace (`speech-studio --audio`) adds native file selection, play/pause/resume/stop, seeking, position, and a canvas waveform with a moving playhead. File loading and output-device lifecycle run on a dedicated worker; a short UI timer reads its synchronized snapshot. The waveform is reduced to at most 240 peak bins before rendering. WAV, FLAC, MP3, OGG/Vorbis, AAC/M4A and AIFF have bundled decoder fixtures. MP4 is decoded directly through Symphonia into a seekable sample buffer because Rodio 0.20.1's MP4 adapter does not provide the byte length required by Symphonia; that route caps decoded memory at 256 MiB and duration at ten minutes. The workspace also loads bounded SRT or version 1 JSON transcript projects, highlights the cue containing the playback position, seeks when a cue is selected, and supports validated cue-boundary edits with 20-entry undo/redo. Project files store transcript cues only, never source audio paths. JSON projects use the shared `Transcript` schema and round-trip through the SRT parser before load or save. All six local decoder fixtures and the MP4 seek regression pass; hosted checks for the current correction are pending. Physical-device playback, platform output backends and latency have not been verified. Recording and richer transcript content editing remain open.

Limitations: Separate English Tiny and multilingual Tiny model packs are supported but are not included in the default build or source tree. The app does not download models. Optional native inference requires a pinned local pack or an explicit model path and SHA-256; a user-supplied hash is integrity, not authenticity. Multilingual mode uses Whisper language auto-detection, but language-level accuracy, WER/CER, and CPU runtime RAM have not been measured. Cancellation cannot interrupt inference itself. Translation, diarization and TTS remain open. SRT supports strict basic timecodes and sequential indices; overlapping segments allowed.
